# DEFENXUS - Defend the Crystal

로그라이크 스타일의 생존 게임. 20개 파동을 버티며 중앙의 수정을 지키세요!

## 🎮 게임 방식

### 기본 게임플레이
- **목표**: 20개 파동을 클리어하고 수정을 지키기
- **조작**: 화살표 키 또는 WASD로 이동
- **공격**: 자동으로 근처 적 공격
- **통화**: 정수(✦) - 적 처치로 획득

### 파동 시스템
- 각 파동마다 점점 더 강해지는 적들이 등장
- 파동 클리어 시 **수정 업그레이드** 선택 가능
  - 수정 회복
  - 최대 체력 증가
  - 정수 보너스
  - 방어막

### 레벨업 시스템
- 10마리 적을 처치할 때마다 레벨업
- 4가지 강화 중 1개 선택:
  - 체력 회복 / 최대 체력 증가
  - 공격력 증가
  - 이동 속도 증가
  - 공격 범위 / 속도 증가

### 상점 (영구 강화)
- **정수 10개 = 영혼조각 1개**
- 영혼조각으로 영구 능력치 구매
  - 최대 체력 부스트
  - 공격력 부스트
  - 이동 속도 부스트
  - 자동 회복
  - 정수 수집 보너스

## 🚀 빠른 시작

### Linux/Mac
```bash
./run-game.sh
```

### Windows
`run-game.bat` 더블클릭

### 수동 실행
```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속

## 📱 모바일 접속

1. 컴퓨터에서 서버 실행: `./run-game.sh`
2. IP 주소 확인: `hostname -I`
3. 모바일 브라우저에서 접속: `http://[IP]:8000`

## 🎯 게임 팁

### 초반 전략
- 스타트: 수정 근처에서 방어하면서 경험 쌓기
- 레벨 5 이전에 체력 강화 우선
- 공격력은 나중에 올려도 괜찮음

### 중반 전략 (파동 5-10)
- 공격 범위/속도 업그레이드로 효율 높이기
- 이동 속도 높여서 적을 피하기
- 영혼조각 모으기 시작

### 후반 전략 (파동 11-20)
- 영구 능력치로 선제 강화하기
- 회복 업그레이드로 생존율 높이기
- 최대 체력을 계속 올리기

## ⚙️ 게임 설정

### 적 타입
| 이름 | HP | 데미지 | 속도 | 보상 |
|------|----|----|------|------|
| 잡졸 | 20 | 5 | 80 | 10 |
| 주자 | 15 | 8 | 120 | 15 |
| 보병 | 50 | 10 | 60 | 25 |
| 보스 | 200 | 20 | 100 | 100 |

### 난이도 배율
- 체력: 각 파동마다 15% 증가
- 공격력: 각 파동마다 10% 증가
- 속도: 각 파동마다 5% 증가
- 생성 수: 각 파동마다 20% 증가

## 🔧 기술 사양

- **엔진**: Canvas 2D + Vanilla JavaScript
- **해상도**: 반응형 (모든 기기 지원)
- **멀티플레이**: BroadcastChannel API (같은 브라우저 탭 간 통신)
- **저장소**: LocalStorage (영구 능력치 저장)
- **성능**: 60 FPS 목표

## 📊 진행 상황 추적

### 통계
- 최고 도달 파동
- 총 처치 적 수
- 총 획득 정수
- 보유 영혼조각

모든 통계는 LocalStorage에 저장되며, 브라우저 데이터를 삭제하면 초기화됩니다.
