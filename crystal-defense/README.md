# 크리스탈 디펜스 (Crystal Defense)

Three.js 기반 3D 웨이브 디펜스 게임. **파밍 → 건설/업그레이드 → 웨이브 방어**의 순환 구조 위에,
동물 사냥·요리, 타워 탑승, 전초기지로 영역 확장, 포탈 봉쇄, 위험 계약(판 강도 자율 선택),
펫 길들이기, 정수 스킬 같은 여러 전략 축이 겹쳐 있다.

목표는 표준 10웨이브 생존이지만, 그 뒤로 엔드리스 모드가 이어진다.

> **⚠️ 정확한 수치의 유일한 소스는 게임 자체다.** 밸런스·비용·확률은 자동 개선 루틴이 수시로
> 바꾸므로, 이 문서는 정확한 숫자를 옮겨 적지 않는다. 실제 수치가 궁금하면:
> - 게임 안에서 **H**(도움말)를 누른다 — 조작·건물·몬스터·시스템 설명이 항상 최신 상태로 뜬다.
> - `js/config.js`를 연다 — 모든 밸런스 수치(비용·체력·피해·확률)가 이 파일 하나에 있다.
> - `crystal-defense/IMPROVEMENTS.md`의 완료 기록 — 무엇이 왜 이렇게 만들어졌는지 설계 의도가
>   전부 남아 있다.

싱글 플레이와 멀티플레이(같은 브라우저 방 만들기/참여, 또는 다른 기기 간 릴레이 서버)를 모두 지원한다.

## 실행 방법

### 방법 1: 더블클릭 (가장 간단, 서버 불필요)

`크리스탈디펜스.html` 파일을 더블클릭하면 브라우저에서 바로 실행된다.
전체 게임(JS + CSS + Three.js)이 파일 하나에 번들링되어 있어 서버도, 인터넷 연결도 필요 없다.

이 파일은 원본 소스(`index.html` + `js/*.js` + `css/style.css`)에서 자동 생성된 배포용 산출물이다.
소스를 수정한 뒤에는 아래 명령으로 다시 빌드한다:

```bash
cd crystal-defense
./build-standalone.sh
```

### 방법 2: 로컬 서버 (개발용, 소스 수정 시 실시간 반영)

```bash
cd crystal-defense
python3 -m http.server 8000
```

브라우저로 `http://localhost:8000`에 접속한다. `index.html`이 ES 모듈(`js/main.js`)을 그대로
불러오므로 `file://`로는 CORS에 막혀 동작하지 않는다 — 반드시 로컬 서버를 거쳐야 한다.

## 게임 루프

1. **파밍** — 나무·돌·구리·석탄·철(제련 필요) 등 여러 재료를 캐거나, 주위를 돌아다니는 동물을
   사냥해 고기를 얻어 화로에 굽는다.
2. **건설·업그레이드** — 제작대를 지어야 다른 건물을 지을 수 있다. 타워는 재질 단계(나무→석조→
   강철)로 업그레이드되며 단계마다 요구 재료가 다르다. 정비소·병기창·치유소 같은 자동화 건물,
   함정류, 전초기지(건설 구역 자체를 확장)도 있다.
3. **웨이브 방어** — 준비 시간마다 포탈 봉쇄·위험 계약(더 세게 받는 대신 보상 증가)을 선택할 수
   있고, 전투 중에는 직접 싸우거나 타워에 탑승해 조작할 수 있다.
4. **성장** — 웨이브 클리어 보상으로 정수를 얻어 정수 스킬·크리스탈 강화에 투자하고, 펫을
   길들이고, 판이 끝나면 영구 성장(원정 준비 퍽)에 쓸 자원이 남는다.

## 멀티플레이

같은 브라우저에서는 로비의 **방 만들기 / 코드로 참가**만으로 별도 서버 없이(BroadcastChannel)
플레이할 수 있다. 다른 기기끼리 붙으려면 `server/relay.js`(외부 패키지 없이 Node 기본 모듈만
사용하는 아주 작은 WebSocket 릴레이)를 띄운다:

```bash
node server/relay.js          # 기본 포트 8080
PORT=9000 node server/relay.js
```

로비 → *멀티플레이 서버 설정* 에 `ws://<서버-IP>:8080` 입력.

가장 먼저 접속한 사람이 **호스트**가 되어 몬스터·웨이브·자원·건설을 계산하고, 나머지는 스냅샷을
받아 그린다. 각자의 캐릭터 위치·체력은 본인 클라이언트가 소유해 실시간 브로드캐스트한다.
호스트가 나가면 다음 사람이 하트비트 타임아웃 뒤 자동으로 승계하며, 진행 중이던 웨이브도 그대로
이어진다. 릴레이 서버는 방 인원과 프레임 크기에 상한을 둬 한 명이 서버 자원을 무한정 먹는 것을
막는다.

## 구조

| 파일 | 역할 |
|---|---|
| `js/config.js` | 모든 밸런스 수치 (건물·몬스터·보스·웨이브·아이템·업그레이드·비용) |
| `js/scene.js` | 렌더러 · 조명 · 지면 · 추적 카메라 · 포인터 레이캐스트 |
| `js/grid.js` | 건설 격자(전초기지로 확장되는 구역 포함) + 몬스터 경로용 플로우 필드 |
| `js/world.js` | 크리스탈 · 자원 노드 · 스폰 포탈 · 지형(biome) (시드 기반 생성) |
| `js/player.js` | 로컬/원격 플레이어, 이동·충돌·채집 채널링·전투·펫 |
| `js/buildings.js` | 고스트 배치 · 충돌 체크 · 업그레이드 · 타워 사격 · 자동화 건물 |
| `js/enemy.js` | 몬스터 · 변종 · 보스 패턴, 경로 추적 · 벽 파괴 · 크리스탈 공격 |
| `js/wave.js` | 준비 시간 → 스폰 → 클리어 보상 흐름, 특수 웨이브 |
| `js/game.js` | 상태 관리 · 입력 처리 · 호스트 권위 시뮬레이션 · 스냅샷 · 스킬 |
| `js/ui.js` | HUD · 인벤토리 · 미니맵 · 이름표 · 로비 · 결과 화면 · 스킬 바 |
| `js/net.js` | 방 접속(BroadcastChannel / WebSocket) · 호스트 선출 · 승계 |
| `js/audio.js` | Web Audio로 합성하는 효과음 (외부 파일 없음) |
| `js/achievements.js` | 업적 정의 · 잠금 해제 판정 |
| `js/bestiary.js` | 도감(발견한 몬스터·오브젝트 기록) |
| `js/meta.js` | 판을 넘나드는 영구 성장(원정 준비 퍽) |
| `js/fx.js` | 파티클·링 등 화면 이펙트 |
| `js/keymap.js` | 키 재지정 · 저장 (기본값·설명은 이 파일이 단일 소스) |
| `js/input.js` | 키보드·마우스·터치 입력 취합 |
| `js/utils.js` | 자원 종류(`COST_KEYS`)·아이콘 등 공용 상수/헬퍼 |
| `server/relay.js` | 기기 간 플레이용 WebSocket 릴레이 (선택) |
| `vendor/three.module.js` | Three.js r160 (MIT, `vendor/three.LICENSE`) |
| `IMPROVEMENTS.md` | 자동 개선 루틴의 작업 노트 — 규칙·완료 기록·설계 의도 |

## 조작

키는 전부 재지정 가능하다(로비/일시정지 화면). 기본값은 `js/keymap.js`의 `DEFAULTS`가 단일
소스이며, 게임 내 도움말(**H**)에 항상 최신 상태로 표시된다. 대략적인 범주만 요약하면:

- **이동·기본 행동**: WASD 이동, 채집/공격, 막기, 회피 돌진, 인벤토리, 일시정지
- **건설**: 업그레이드/수리/철거/이동 모드, 각 건물 단축키(인벤토리 건설 탭에 표시)
- **정수 스킬**: 회복 등 7종, 화면 좌하단 스킬 바로도 클릭/탭 가능
- **상호작용(근접)**: 채집, 동물 길들이기, 타워 탑승, 재장전, 포탈 봉쇄 — 전부 대상 근처에 서면
  화면에 안내 프롬프트가 뜨고, 모바일에서는 같은 자리에 터치 버튼이 나타난다
- **모바일**: 조이스틱 이동 + 탭 공격/채집 + 근접 상호작용 버튼 + 막기/회피 돌진 전용 버튼
