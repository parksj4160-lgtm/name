# 크리스탈 디펜스 (Crystal Defense)

Three.js 기반 3D 웨이브 디펜스 게임. **파밍 → 건설/업그레이드 → 웨이브 방어**의 순환 구조로,
자원은 언제나 모자라고 매 웨이브마다 "벽을 더 지을까, 타워를 지을까, 업그레이드를 할까"를 고민하게 된다.
목표는 **10웨이브 생존**.

싱글 플레이와 멀티플레이(방 만들기/참여)를 모두 지원한다.

## 실행 방법

### 방법 1: 더블클릭 (가장 간단, 서버 불필요)

`크리스탈디펜스.html` 파일을 더블클릭하면 브라우저에서 바로 실행된다.
전체 게임(JS + CSS + Three.js)이 파일 하나에 번들링되어 있어 서버도, 인터넷 연결도 필요 없다.

이 파일은 원본 소스(`index.html` + `js/*.js` + `css/style.css`)에서 자동 생성된 배포용 산출물이다.
소스를 수정한 뒤에는 아래 명령으로 다시 빌드한다:

```bash
cd crystal-defense
./build-standalone.sh
```

### 방법 2: 로컬 서버 (개발용, 소스 수정 시 실시간 반영)

```bash
cd crystal-defense
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000> 접속.
Three.js는 `vendor/` 에 포함되어 있어 **인터넷 연결 없이도** 동작한다. 빌드 도구도 필요 없다.

> `index.html` 을 직접 더블클릭해 파일로 여는 방식은 ES 모듈 보안 정책 때문에 동작하지 않는다 — 이 경우엔 로컬 서버를 쓰거나, 위의 번들된 `크리스탈디펜스.html` 을 사용할 것.

## 조작

| 동작 | 조작 |
|---|---|
| 이동 | `W` `A` `S` `D` / 방향키 (`Shift` 달리기) |
| 채집 | 자원 근처에서 `F` 꾹 누르기 (이동하면 취소). 💠 정수석은 **곡괭이를 손에 쥐어야** 캔다 |
| 공격 | 좌클릭 또는 `Space` |
| 인벤토리 | `I` — 건설 · 제작 · 장비를 전부 여기서 고른다 |
| 건설 | 인벤토리 **건설** 탭 → 좌클릭으로 배치. 벽·타워는 **제작대를 먼저 지어야** 열린다 (숫자 `1`~`8` 단축키도 동작) |
| 제작 | 인벤토리 **제작** 탭 (제작대·화로를 지어야 열린다) |
| 장비 | 인벤토리 **장비** 탭에서 고르면 손에 든다 (곡괭이 포함) |
| 업그레이드 | `U` 누르고 건물 클릭 |
| 수리 | `G` 누르고 건물 클릭 |
| 철거 (50% 환급) | `X` 누르고 건물 클릭 |
| 웨이브 시작 | `Enter` (준비 시간이 끝나면 자동 시작) |
| 수정 정수 사용 | `R` — 크리스탈 25% 회복 |
| 카메라 | 우클릭 드래그 회전 · 휠 확대/축소 |
| 취소 | `Esc` 또는 우클릭 |
| 도움말 | `H` |

모바일은 화면 좌측 조이스틱 + 우측 버튼 하나로 조작한다. 버튼은 상황에 따라 바뀌어서,
캘 것이 앞에 있으면 **채집**(꾹 누르기), 없으면 **공격**(누르기)이 된다.

## 게임 규칙

### 자원
- **목재(🪵)**: 나무 채집. 1회 6개, 나무 한 그루당 4회 → 22초 뒤 리스폰
- **광물(🪨)**: 바위 채집. 1회 5개, 바위 하나당 3회 → 28초 뒤 리스폰
- **정수석(💠)**: 곡괭이를 만들고 **손에 쥔 채로만** 캘 수 있다.
- **철(⚙️)**: 채집으로는 못 얻는다. 화로에서 광물을 녹여야 나온다.
- 채집에는 시간이 걸리고 그동안 무방비다. 몬스터가 근처에 오면 얻어맞는다.
- 채집 속도는 자원을 써서 3단계까지 업그레이드할 수 있다 (최대 채집 시간 45%).

### 건설
| 건물 | 비용 | 역할 |
|---|---|---|
| 🧱 벽 | 🪵12 🪨4 | 몬스터의 이동 경로를 막는다 |
| 🏹 화살탑 | 🪵35 🪨15 | 빠른 단일 공격 |
| ❄️ 서리탑 | 🪵25 🪨45 | 명중한 적을 느리게 만든다 |
| 💣 대포탑 | 🪵55 🪨70 | 느리지만 범위 피해 |
| ☠️ 독탑 | 🪵30 🪨50 | 맞은 적이 시간에 걸쳐 계속 닳는다 |
| 🛡️ 보루 | 🪵40 🪨60 | 주변 타워의 공격력을 올린다 |
| 🪚 제작대 | 🪵20 | 인벤토리 제작 탭을 연다 (도구·무기) |
| 🔥 화로 | 🪵15 🪨30 | 인벤토리 제작 탭에서 광물을 녹여 철을 얻는다 |

- 배치 전 **고스트(반투명 미리보기)** 로 위치를 확인한다. 초록이면 배치 가능, 빨강이면 불가.
- 건설 가능 구역(크리스탈 중심 반경 22)의 격자 위에만 지을 수 있고, 크리스탈 바로 옆·자원 노드 위·이미 건물이 있는 칸에는 지을 수 없다.
- 모든 건물은 3레벨까지 업그레이드된다. 벽은 내구도, 타워는 공격력·사거리·연사 속도가 오른다.

### 인벤토리

`I` 키나 화면 아래 **🎒 인벤토리** 버튼으로 연다. 예전의 하단 단축키 바를 대체하며 세 탭으로 나뉜다.

| 탭 | 하는 일 |
|---|---|
| 건설 | 제작대·화로는 처음부터, 벽·타워는 **제작대를 지은 뒤에** 고를 수 있다. 업그레이드·수리·철거 모드도 여기 있다 |
| 제작 | 도구와 무기를 만들고, 광물을 녹여 철을 얻는다 |
| 장비 | 만든 도구·무기 중 하나를 손에 든다 |

제작대나 화로를 클릭해도 **제작** 탭이 바로 열린다.

### 제작 (제작대 · 화로)

제작 탭은 해당 시설을 **지어 두어야** 열린다. 제작대가 없으면 도구 칸이, 화로가 없으면 제련 칸이 잠긴다.

**🔥 화로** — 광물을 녹여 철을 만든다.

| 제련 | 비용 | 결과 |
|---|---|---|
| 철 | 🪨6 | ⚙️1 |

**🪚 제작대** — 만든 것은 각자 하나씩만 가질 수 있고, 다시 만들 수 없다.

| 제작품 | 비용 | 효과 |
|---|---|---|
| ⛏️ 곡괭이 | 🪵15 | **손에 쥐고 있는 동안** 정수석을 캘 수 있다 |
| 🗡️ 칼 | 🪵10 ⚙️4 | 근접 공격력 +12 (16 → 28) |
| 🏹 활 | 🪵20 ⚙️3 | 공격 사거리 +2.4 (2.8 → 5.2) · 공격 범위도 넓어진다 |

**무기는 한 번에 하나만 든다.** 인벤토리 **장비** 탭에서 고른 무기의 효과만 적용되고,
캐릭터 손에도 그 무기가 보인다 (맨손을 고르면 아무것도 들지 않는다).
아무것도 고르지 않으면 칼 → 활 순으로 자동으로 든다.

무기는 자기 캐릭터에만 붙는다. 멀티플레이에서는 각자 따로 만들어야 하고,
상대가 든 무기도 서로에게 보이며, 호스트가 바뀌어도 그대로 이어진다.

### 웨이브
- 준비 시간은 첫 웨이브 75초, 이후 60초. `웨이브 시작` 버튼으로 앞당길 수 있고, 시간이 다 되면 자동으로 시작된다.
- 몬스터는 맵 네 귀퉁이의 포탈에서 나와 크리스탈로 진격한다.
  - **그런트** 표준형 / **러너** 빠르고 약함 / **브루트** 느리고 단단함 / **주술사** 벽을 무시하고 멀리서 크리스탈 저격 / **약탈자** 가장 가까운 건물로 직행
  - 5웨이브마다 **보스(파괴자)**. 단순한 큰 덩어리가 아니라 패턴이 있다:
    - **소환** — 체력이 72% · 46% · 22% 아래로 떨어질 때마다 제자리에 서서 잡졸 3마리를 부른다
    - **돌진** — 크리스탈에서 9 이상 떨어져 있으면 쿨다운마다 크리스탈을 향해 직선으로 밀고 들어오며, 스치는 건물을 부순다
    - 두 패턴 모두 **1초 남짓 예고**가 먼저 뜬다 (고리 표시 + 경고). 그 사이에 피하거나 화력을 쏟아붓는 게 핵심이다.
    - 멀티플레이에서는 참가자에게도 예고가 전달된다.
  - 웨이브마다 체력·공격력·수가 증가한다.
- 웨이브를 클리어하면 자원 보상을 받고, 3웨이브마다 **수정 정수(💠)** 를 얻는다 (`R` 로 크리스탈 25% 회복).
- 크리스탈 HP가 0이 되면 게임 오버, 10웨이브를 막아내면 승리.

### 길막기와 경로
몬스터의 경로는 다익스트라 **플로우 필드**로 계산한다. 벽은 "통과할 수 있지만 아주 비싼 칸"으로 취급되므로

- 길이 열려 있으면 몬스터는 벽을 **돌아서** 간다.
- 완전히 둘러싸면 가장 **약한 벽을 부수고** 들어온다. (미로를 만들어 동선을 늘리는 전략이 유효하다)

## 멀티플레이

파티원은 **실제로 접속한 사람만** 채워진다. AI 동료는 없다.

1. 로비에서 **방 만들기** → 4자리 방 코드 생성
2. 상대는 같은 화면에서 코드를 입력하고 **참여**
3. 방장이 **게임 시작** (자원을 팀 공유로 할지, 개인 소유로 할지 선택 가능)

- **팀 공유 자원**: 모두가 같은 창고를 쓴다. 역할 분담(파밍 담당 / 건설 담당)이 자연스럽게 나온다.
- **개인 자원**: 각자 따로 모으고, 파티 목록의 `🪵10` `🪨10` 버튼으로 서로에게 전달할 수 있다.

동기화 방식:

- 기본값은 `BroadcastChannel` → **같은 브라우저의 다른 탭/창**끼리 연결된다 (설치 불필요).
- 다른 기기(친구 PC / 휴대폰)와 하려면 릴레이 서버를 켜고 로비 하단 설정에 주소를 넣는다.

```bash
node server/relay.js          # 기본 포트 8080, 외부 패키지 불필요
```

로비 → *멀티플레이 서버 설정* 에 `ws://<서버-IP>:8080` 입력.

가장 먼저 접속한 사람이 **호스트**가 되어 몬스터·웨이브·자원·건설을 계산하고, 나머지는 스냅샷(12Hz)을 받아 그린다.
각자의 캐릭터 위치와 체력은 본인 클라이언트가 소유해 15Hz로 브로드캐스트한다.
호스트가 나가면 다음 사람이 자동으로 승계하며, 진행 중이던 웨이브도 그대로 이어진다.
