# 크리스탈 디펜스 — 자동 개선 백로그

이 파일은 **5시간마다 자동으로 실행되는 개선 루틴**이 읽고 쓰는 작업 노트다.
각 실행은 새로운 세션에서 시작하므로, 이 파일이 유일한 연속성의 근거가 된다.

## 규칙

1. 한 번의 실행에서 **의미 있는 개선 하나**만 완결한다. 여러 개를 얕게 건드리지 않는다.
2. 기존 게임플레이를 깨뜨리지 않는다. 작업 후 반드시 헤드리스 브라우저로 검증한다.
3. 작업이 끝나면 `./build-standalone.sh` 로 단일 파일을 다시 빌드한다.
4. 아래 **완료 기록**에 무엇을 왜 했는지 한 줄로 남기고, 백로그에서 해당 항목을 제거한다.
5. 백로그가 비면, 직접 플레이 테스트를 해보고 새 항목을 발굴해 채운다.

## 백로그 (우선순위 순)

- [ ] **사운드** — Web Audio API로 효과음 합성 (외부 파일 없이). 타격, 건설, 채집, 웨이브 시작, 크리스탈 피격. 음소거 토글 포함.
- [ ] **타격감** — 몬스터 피격 시 히트 플래시 · 넉백 · 화면 흔들림(보스 처치 시). 지금은 데미지가 들어가도 반응이 밋밋하다.
- [ ] **모바일 조작** — 조이스틱 반응성 개선, 건설 모드에서 탭-투-배치 UX 정리, 세로 화면 대응.
- [ ] **난이도 곡선** — 실제 플레이 데이터 기준으로 웨이브 3~6 구간이 헐겁고 8~10이 급격한지 점검하고 튜닝.
- [ ] **몬스터 다양성** — 원거리 공격형 또는 타워를 우선 노리는 유형 추가. 벽 세우기 전략이 단조로워지는 걸 막는다.
- [ ] **타워 다양성** — 독/감전 등 지속 피해 타워, 또는 주변 타워를 강화하는 보조 건물.
- [ ] **통계 화면** — 최고 웨이브 · 총 처치 수 · 플레이 횟수를 localStorage에 기록하고 결과 화면에 표시.
- [ ] **성능** — 몬스터·건물이 많아질 때 InstancedMesh 도입 검토. 현재 120채 + 10마리에서는 문제 없으나 후반 웨이브 여유 확보.
- [ ] **접근성** — 색약 모드(적/아군 구분을 색 외 형태로도), 키 리바인딩.
- [ ] **튜토리얼** — 첫 플레이 시 채집 → 건설 → 웨이브 흐름을 3단계로 안내하는 오버레이.
