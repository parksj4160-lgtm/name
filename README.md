# 2D 횡스크롤 RPG

가로 화면 전용 2D 횡스크롤 RPG. 플레이어는 항상 화면 중앙에 고정되고 월드가 스크롤된다.

## 실행 방법

```bash
cd name
python -m http.server 8000
```

브라우저에서 <http://localhost:8000> 접속. (`python3` 인 환경도 있음)

> 파일을 직접 열어도(`index.html` 더블클릭) 동작하지만, 로컬 서버로 여는 것을 권장한다.

## 조작

| 동작 | 키보드 | 모바일 |
|---|---|---|
| 이동 | `A` / `D` 또는 ← → | 좌측 ◀ ▶ 버튼 |
| 점프 | `Space` / `W` / ↑ | 우측 ↑ 버튼 |
| 공격 | `J` / `Z` / `K` | 우측 ⚔ 버튼 |
| 상호작용 | `E` / `F` | 화면 중앙 하단 프롬프트 탭 |

`E`는 상호작용 대상이 없으면 공격으로 동작한다.

## 진행 흐름

광장(마을) → 사냥터에서 레벨업/골드 → 장비 상점에서 철검 구매·강화 → 회복 상점 →
던전(3웨이브 + 보스) 클리어 → 계단/포탈로 다음 층 이동. 층마다 시간대와 몬스터가 달라진다 (1F 낮 / 2F 노을 / 3F 밤).

## 멀티플레이 (파티)

파티원은 **실제로 접속한 사람만** 채워진다. AI 더미 동료는 없다.

1. 하단 `파티` 버튼 또는 던전 앞에서 상호작용 → 파티 로비
2. **방 만들기** → 4자리 방 코드가 생성됨
3. 상대는 같은 화면에서 코드를 입력하고 **참여**
4. 파티 슬롯이 채워지면 각자 **던전 입장**

동기화 방식:

- 기본값은 `BroadcastChannel` → **같은 브라우저의 다른 탭/창**끼리 연결된다 (설치 불필요).
- 다른 기기(친구 PC / 휴대폰)와 하려면 릴레이 서버를 켜고 설정에 주소를 넣는다.

```bash
node server/relay.js          # 기본 포트 8080, 외부 패키지 불필요
```

게임 내 ⚙ 설정 → *멀티플레이 서버* 에 `ws://<서버-IP>:8080` 입력.

던전에서는 가장 먼저 접속한 사람이 **호스트**가 되어 몬스터를 계산하고, 나머지는 스냅샷을 받는다.
호스트가 나가면 다음 사람이 자동으로 승계한다. 경험치·골드는 파티 전원이 함께 받는다.

## 구조

| 파일 | 역할 |
|---|---|
| `js/camera.js` | 플레이어 중앙 고정 카메라 (`screenX = worldX - camera.x`) |
| `js/character.js` | 캐릭터 렌더러 (걷기 / 점프 / 공격 스윙 모션) |
| `js/scenery.js` | 패럴랙스 배경, 건물, 던전 장식 |
| `js/fx.js` | 데미지 숫자, 파티클, 슬래시 궤적, 화면 흔들림 |
| `js/combat.js` | 근접 공격 판정 / 치명타 / 보상 |
| `js/net.js` | 방 접속, 호스트 선출, 메시지 중계 |
| `js/party.js`, `js/remotePlayer.js` | 실제 접속 플레이어 관리 및 보간 |
| `js/world.js`, `js/huntingArea.js`, `js/dungeon.js` | 광장 / 사냥터 / 던전 씬 |
| `js/gameManager.js` | 상태·씬 전환·네트워크 연결 |
| `server/relay.js` | 기기 간 플레이용 WebSocket 릴레이 (선택) |
